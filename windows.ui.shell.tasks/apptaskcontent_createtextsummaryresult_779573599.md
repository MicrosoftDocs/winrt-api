# Windows.UI.Shell.Tasks.AppTaskContent.CreateTextSummaryResult(System.String)

<!--
public static Windows.UI.Shell.Tasks.AppTaskContent CreateTextSummaryResult (string text);
-->


## -description

Creates task content that displays a text summary of the task result.

## -parameters

### -param text

A short description summarizing the task result.

## -returns

A new [AppTaskContent](apptaskcontent.md) object that displays a text summary.

## -remarks

Use this content type when a task completes and you want to provide a brief text description of the result.
