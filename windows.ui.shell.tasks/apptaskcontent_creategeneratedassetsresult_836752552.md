# Windows.UI.Shell.Tasks.AppTaskContent.CreateGeneratedAssetsResult(Windows.UI.Shell.Tasks.AppTaskResultAsset[])

<!--

## -description

Creates task content that displays a collection of assets generated by the task.

## -parameters

### -param assets

An array of [AppTaskResultAsset](apptaskresultasset.md) objects that represent the generated content.

## -returns

A new [AppTaskContent](apptaskcontent.md) object that displays the generated assets.

## -remarks

Use this content type when a task produces files or other content that you want to display to the user.
