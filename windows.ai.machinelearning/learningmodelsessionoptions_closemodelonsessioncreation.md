# Windows.AI.MachineLearning.LearningModelSessionOptions.CloseModelOnSessionCreation

## -description

> [!IMPORTANT]
> For the latest documentation about Windows Machine Learning, see [What is Windows ML](/windows/ai/new-windows-ml/overview). That documentation describes APIs that are in the **Microsoft.Windows.AI.MachineLearning** namespace, which ships in the Windows App SDK. Those APIs supersede the ones documented here, which are in the **Windows.AI.MachineLearning** namespace, and were shipped in 2018.

Specifies whether a [LearningModelSession](learningmodelsession.md) should close the associated learning model when it is created.

## -property-value
Indicates whether the model should be closed upon session creation.
