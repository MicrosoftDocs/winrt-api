# Windows.Media.ClosedCaptioning.ClosedCaptionTheme.TrySetSelectedTheme(Windows.Media.ClosedCaptioning.ClosedCaptionTheme)

<!--
public static bool TrySetSelectedTheme (Windows.Media.ClosedCaptioning.ClosedCaptionTheme value);
-->


## -description

Sets the specified theme as the currently selected closed caption theme for the current user.

## -parameters

### -param value

The [ClosedCaptionTheme](closedcaptiontheme.md) to set as the selected theme.

## -returns

**true** if the theme was successfully set; otherwise, **false**. A return value of **false** may indicate that the specified theme is no longer available.
