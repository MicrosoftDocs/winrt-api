# Windows.Management.Deployment.PackageOperationPriority

<!--
public enum PackageOperationPriority
-->


## -description

Defines constants that specify the priority of add or stage operation on a package.

## -enum-fields

### -field Low: 0

Specifies that the package operation will be executed with Low priority.

### -field Normal: 1

Specifies that this is the default value and the package operation will be executed with Normal priority.

### -field High: 2

Specifies that the package operation will be executed with High priority.

## -remarks

> [!NOTE]
> **PackageOperationPriority** is available starting with Windows 11 24H2, version 26100 (11D revision).
