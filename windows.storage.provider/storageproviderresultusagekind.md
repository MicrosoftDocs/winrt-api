# Windows.Storage.Provider.StorageProviderResultUsageKind

<!--
public enum StorageProviderResultUsageKind
-->

## -description

Defines the possible usage kinds for a storage provider result.

## -enum-fields

### -field Rendered: 0

The result is being rendered to the user.

### -field Opened: 1

The result is being opened.

### -field SuggestionResponseReceived: 2

The result is being used in a suggestion response.
