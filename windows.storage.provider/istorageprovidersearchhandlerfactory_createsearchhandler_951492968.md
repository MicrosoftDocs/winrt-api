# Windows.Storage.Provider.IStorageProviderSearchHandlerFactory.CreateSearchHandler(System.String)

<!--
public Windows.Storage.Provider.IStorageProviderSearchHandler CreateSearchHandler (string cloudProviderId);
-->

## -description

Creates a search handler for a given sync root identifier.

## -parameters

### -param cloudProviderId

The sync root identifier for the cloud files provider, see [SyncRootId](./storageprovidersyncrootinfo_id.md).

## -returns

Returns a search handler that can be used to search for files and folders in the cloud files provider.
