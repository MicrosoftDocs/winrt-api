# Windows.Storage.Provider.StorageProviderSearchQueryOptions.SortOrder

<!--
public System.Collections.Generic.IReadOnlyList<Windows.Storage.Search.SortEntry> SortOrder { get; }

## -description

Gets the order that the results should be returned in, using rank as the default sort order.

## -property-value

The sort order for the search query as a read-only list of [SortEntry](../windows.storage.search/sortentry.md) objects.
