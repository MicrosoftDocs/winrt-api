# Windows.Storage.Provider.IStorageProviderSuggestionsHandlerFactory

<!--
public interface IStorageProviderSuggestionsHandlerFactory
-->

## -description

Enables the cloud provider to provide suggestions for files and folders in a location that the provider manages.

## -remarks

Activated in the cloud provider process as a local server and creates a suggestions handler for a given sync root identifier.
