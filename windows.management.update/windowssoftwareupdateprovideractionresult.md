# Windows.Management.Update.WindowsSoftwareUpdateProviderActionResult

<!--

## -description

Describes the outcome that a provider reports for a software-update action, including the result, any required restart, and error information.

## -remarks

A provider passes an instance of this class to [WindowsSoftwareUpdateProviderStatus.SetActionResult](./windowssoftwareupdateproviderstatus_setactionresult_217546004.md) when an action finishes.
