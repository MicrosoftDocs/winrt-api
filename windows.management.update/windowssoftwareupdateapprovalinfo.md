# Windows.Management.Update.WindowsSoftwareUpdateApprovalInfo

<!--

## -description

Describes the conditions under which a [WindowsSoftwareUpdate](./windowssoftwareupdate.md) is approved to proceed.

## -remarks

Pass an instance of this class to [WindowsSoftwareUpdate.Approve](./windowssoftwareupdate_approve_49594770.md) to control how and when an update is allowed to run. The current approval state of an update is available from [WindowsSoftwareUpdate.ApprovalInfo](./windowssoftwareupdate_approvalinfo.md).
