# Windows.Management.Update.WindowsSoftwareUpdateOptionalInfo

<!--
public sealed class WindowsSoftwareUpdateOptionalInfo
-->


## -description

Carries optional metadata for a [WindowsSoftwareUpdate](./windowssoftwareupdate.md), including its category, localized content, and compliance timing.

## -remarks

All values are optional. Supply `null` for any component that doesn't apply to your update.
