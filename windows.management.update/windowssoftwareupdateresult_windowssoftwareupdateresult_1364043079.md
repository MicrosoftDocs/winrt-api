Creates a new [WindowsSoftwareUpdateResult](./windowssoftwareupdateresult.md) with a success flag, cancellation flag, result code, and extended error.

## -parameters

### -param succeeded

`true` if the operation succeeded; otherwise, `false`.

### -param cancelRequested

`true` if the orchestrator has requested that the operation be canceled; otherwise, `false`.

### -param resultCode

A result code for the operation.

### -param extendedError

Extended error information for the operation.
