# Windows.Management.Update.WindowsSoftwareUpdateScanResult

<!--
public sealed class WindowsSoftwareUpdateScanResult
-->


## -description

Represents the result of a software-update scan, including whether it succeeded and the [WindowsSoftwareUpdate](./windowssoftwareupdate.md) objects that were discovered.

## -remarks

A scan performed through [WindowsUpdateManager.PerformScan](./windowsupdatemanager_performscan_158684574.md) returns a **WindowsSoftwareUpdateScanResult**.
