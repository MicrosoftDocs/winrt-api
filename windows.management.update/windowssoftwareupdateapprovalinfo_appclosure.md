# Windows.Management.Update.WindowsSoftwareUpdateApprovalInfo.AppClosure

<!--
public bool AppClosure { get; }
-->


## -description

Gets a value that indicates whether the update is allowed to close the target application when required to complete an action.

## -property-value

`true` if application closure is allowed; otherwise, `false`.
