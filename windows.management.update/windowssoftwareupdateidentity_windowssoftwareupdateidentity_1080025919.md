## -description

Creates a new [WindowsSoftwareUpdateIdentity](./windowssoftwareupdateidentity.md) for the specified product.

## -parameters

### -param type

A [WindowsSoftwareUpdateIdentityType](./windowssoftwareupdateidentitytype.md) value that specifies how *identity* is interpreted.

### -param identity

The identity string. For **ProductCode** this is an MSI product-code GUID; for **PackageFamilyName** this is an MSIX package family name.
