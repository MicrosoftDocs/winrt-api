# Windows.Management.Update.WindowsSoftwareUpdateProviderPayloadFileInfo

<!--
public sealed class WindowsSoftwareUpdateProviderPayloadFileInfo
-->


## -description

Describes a single payload file that belongs to a [WindowsSoftwareUpdateProvider](./windowssoftwareupdateprovider.md), including its hash and code-signing trust state.

## -remarks

Each file that a provider package declares is represented by one of these entries, which the system uses to verify file integrity and trust during registration and execution.
