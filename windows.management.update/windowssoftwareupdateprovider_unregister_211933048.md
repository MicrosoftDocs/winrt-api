# Windows.Management.Update.WindowsSoftwareUpdateProvider.Unregister

<!--
public Windows.Management.Update.WindowsSoftwareUpdateResult Unregister ();

## -description

Unregisters the provider from the Windows Update Orchestrator so it's no longer scanned.

## -returns

A [WindowsSoftwareUpdateResult](./windowssoftwareupdateresult.md) that indicates whether unregistration succeeded.

## -remarks

Requires administrator privileges.
