# Windows.Management.Update.WindowsSoftwareUpdateAppPackageInfo

<!--

## -description

Describes the MSIX/AppX application package that an [AppPackage](./windowssoftwareupdateinstallationtype.md) [WindowsSoftwareUpdate](./windowssoftwareupdate.md) installs.

## -remarks

Supply this information for updates whose installation type is **AppPackage**. The system uses it to acquire and install the package.
