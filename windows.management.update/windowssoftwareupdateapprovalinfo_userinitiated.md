# Windows.Management.Update.WindowsSoftwareUpdateApprovalInfo.UserInitiated

<!--

## -description

Gets a value that indicates whether the update was approved as a result of a user-initiated request.

## -property-value

`true` if the approval is user-initiated; otherwise, `false`.
