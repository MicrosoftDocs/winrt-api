# Windows.Management.Update.WindowsSoftwareUpdateApprovalInfo.MeteredNetwork

<!--

## -description

Gets a value that indicates whether the update is allowed to download over a metered network.

## -property-value

`true` if downloading over a metered network is allowed; otherwise, `false`.
