# Windows.Management.Update.WindowsSoftwareUpdateVersion

<!--

## -description

Represents a four-part version number (major, minor, revision-major, and revision-minor) for a [WindowsSoftwareUpdate](./windowssoftwareupdate.md).

## -remarks

A provider supplies the source and target versions of an update so the orchestrator and the associated UI can describe what the update changes.
