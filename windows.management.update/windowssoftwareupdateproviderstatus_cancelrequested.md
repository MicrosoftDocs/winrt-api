# Windows.Management.Update.WindowsSoftwareUpdateProviderStatus.CancelRequested

<!--

## -description

Raised when the Windows Update Orchestrator requests that the in-progress action be canceled.

## -remarks

Handle this event to stop long-running work promptly and report a canceled result.
