# Windows.Foundation.Metadata.ProtectedAttribute

## -description
Indicates that the interface contains protected methods.

## -remarks

In MIDL 3.0, protected-interface metadata is expressed with the `[protected(InterfaceName)]` attribute. For an example, see [Synthesizing interfaces (MIDL 3.0)](https://learn.microsoft.com/uwp/midl-3/synthesizing-interfaces).
