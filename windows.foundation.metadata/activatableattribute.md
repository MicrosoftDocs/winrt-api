# Windows.Foundation.Metadata.ActivatableAttribute

## -description
Indicates that the class is an activatable runtime class.

## -remarks

In MIDL 3.0, activation metadata is expressed with the `[activatable(...)]` attribute. For examples, see [Synthesizing interfaces (MIDL 3.0)](https://learn.microsoft.com/uwp/midl-3/synthesizing-interfaces).
