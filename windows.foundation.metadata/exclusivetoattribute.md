# Windows.Foundation.Metadata.ExclusiveToAttribute

## -description
Indicates that the specified type is exclusive to this type.

## -remarks

In MIDL 3.0, exclusive-to metadata is expressed with the `[exclusiveto(TypeName)]` attribute. For examples, see [Synthesizing interfaces (MIDL 3.0)](https://learn.microsoft.com/uwp/midl-3/synthesizing-interfaces).
