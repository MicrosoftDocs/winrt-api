# Windows.Foundation.Metadata.ContractVersionAttribute

## -description
Indicates the version of the API contract.

## -remarks

In MIDL 3.0, contract version metadata is expressed with the `[contract(ContractName, ContractVersion)]` attribute. For details, see [Predefined attributes (MIDL 3.0)](https://learn.microsoft.com/uwp/midl-3/predefined-attributes#the-contract-attribute).
