# Windows.Devices.Printers.IppPrintDeviceKind

<!--
public enum IppPrintDeviceKind
-->


## -description

Specifies the kind of an Internet Printing Protocol (IPP) device.

## -enum-fields

### -field Printer: 0

The device is a printer.

### -field FaxOut: 1

The device is a fax machine.

### -field VirtualPrinter: 2

The device is a virtual printer.
