# Windows.Graphics.Printing.PrintSupport.XpsImageQuality

<!--
public enum XpsImageQuality
-->


## -description

Specifies the image quality of an XPS image.

## -enum-fields

### -field JpegHighCompression: 0

JPEG, high compression.

### -field JpegMediumCompression: 1

JPEG, medium compression.

### -field JpegLowCompression: 2

JPEG, low compression.

### -field Png: 3

PNG, no compression.
