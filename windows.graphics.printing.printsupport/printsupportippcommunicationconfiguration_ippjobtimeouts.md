# Windows.Graphics.Printing.PrintSupport.PrintSupportIppCommunicationConfiguration.IppJobTimeouts

<!--
public Windows.Graphics.Printing.PrintSupport.PrintSupportIppCommunicationTimeouts IppJobTimeouts { get; }
-->


## -description

Gets a [PrintSupportIppCommunicationTimeouts](printsupportippcommunicationtimeouts.md) specifying the timeout intervals for getting and setting IPP jobs.

## -property-value

A [PrintSupportIppCommunicationTimeouts](printsupportippcommunicationtimeouts.md) object.

## -remarks

Setting the timeout intervals will fail if [CanModifyTimeouts](printsupportippcommunicationconfiguration_canmodifytimeouts.md) is false.
