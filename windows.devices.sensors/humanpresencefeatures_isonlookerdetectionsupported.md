# Windows.Devices.Sensors.HumanPresenceFeatures.IsOnlookerDetectionSupported

<!--
public bool IsOnlookerDetectionSupported { get; }
-->


## -description

Gets whether the human presence sensor can detect when an onlooker is present.

## -property-value

True, if supported. Otherwise, false. The default is false.
