# Windows.AI.Actions.Hosting.ActionOverload.InvokeFeedbackAsync(Windows.AI.Actions.ActionInvocationContext,Windows.AI.Actions.ActionFeedback)

<!--

## -description

Asynchronously invokes the feedback for the associated action overload.

## -parameters

### -param context

The invocation context of the associated app action.

### -param feedback

A [ActionFeedback](../windows.ai.actions/actionfeedback.md) object representing the user feedback for an app action.

## -returns

An asynchronous action.
