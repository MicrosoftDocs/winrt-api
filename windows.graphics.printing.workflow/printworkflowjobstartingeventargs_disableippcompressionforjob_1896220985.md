# Windows.Graphics.Printing.Workflow.PrintWorkflowJobStartingEventArgs.DisableIppCompressionForJob

<!--
public void DisableIppCompressionForJob ();
-->


## -description

Disables IPP compression for the current printer job operation.

## -remarks

Determine if IPP compression is enabled for the current printer job operation by checking the value of the [IsIppCompressionEnabled](printworkflowjobstartingeventargs_isippcompressionenabled.md) property.
