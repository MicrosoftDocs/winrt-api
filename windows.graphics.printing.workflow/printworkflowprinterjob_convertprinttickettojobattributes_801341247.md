# Windows.Graphics.Printing.Workflow.PrintWorkflowPrinterJob.ConvertPrintTicketToJobAttributes(Windows.Graphics.Printing.PrintTicket.WorkflowPrintTicket,System.String)

## -description

Converts a [WorkflowPrintTicket](../windows.graphics.printing.printticket.workflowprintticket.md) to Internet Printing Protocol (IPP) job attributes.

## -parameters

### -param printTicket

The **WorkflowPrintTicket** to be converted.

### -param targetPdlFormat

A string specifying the target PDL format

## -returns

A dictionary where the keys are attribute name strings and the values are [IppAttributeValue](../windows.devices.printers/ippattributevalue.md) objects.
