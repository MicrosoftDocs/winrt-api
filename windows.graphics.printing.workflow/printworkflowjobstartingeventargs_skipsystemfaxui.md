# Windows.Graphics.Printing.Workflow.PrintWorkflowJobStartingEventArgs.SkipSystemFaxUI

<!--
public bool SkipSystemFaxUI { get; set; }
-->


## -description

Gets or sets a value that specifies whether the system fax dialing UI should be skipped for the current printer job operation.

## -property-value

True if the system fax UI should be skipped; otherwise, false.

## -remarks

If the printer associated with the current printer job operation is a non-fax printer, setting this property has no effect.
