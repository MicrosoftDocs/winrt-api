# Windows.Foundation.IStringable

## -description
Provides a way to represent the current object as a string.

## -remarks
> [!IMPORTANT]
> Managed types should not implement the IStringable interface. For more info, see [The Windows Runtime and the IStringable Interface](/dotnet/fundamentals/runtime-libraries/system-object-tostring.md#the-windows-runtime-and-the-istringable-interface).
