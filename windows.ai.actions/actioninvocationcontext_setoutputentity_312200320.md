# Windows.AI.Actions.ActionInvocationContext.SetOutputEntity(System.String,Windows.AI.Actions.ActionEntity)

<!--

## -description

Sets the output entity for an app action invocation.

## -parameters

### -param outputName

The name of the output entity. The name must match the name declared in the Action definition JSON file. For more information, see [Action definition JSON schema for App Actions on Windows](/windows/ai/app-actions/actions-json).

### -param outputValue

An instance of one of the entity classes that inherits from [ActionEntity](actionentity.md).
