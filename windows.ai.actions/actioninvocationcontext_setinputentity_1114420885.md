# Windows.AI.Actions.ActionInvocationContext.SetInputEntity(System.String,Windows.AI.Actions.ActionEntity)

<!--

## -description

Sets the input entity for an app action invocation.

## -parameters

### -param inputName

The name of the input entity. The name must match the name declared in the Action definition JSON file. For more information, see [Action definition JSON schema for App Actions on Windows](/windows/ai/app-actions/actions-json).

### -param inputValue

An instance of one of the entity classes that inherits from [ActionEntity](actionentity.md).
