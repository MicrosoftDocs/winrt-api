# Windows.AI.Actions.ActionInvocationContext.ActionName

<!--

## -description

Gets the name of the app action for the current invocation.

## -property-value

The name of the app action. The action name is declared in the Action definition JSON file. For more information, see [Action definition JSON schema for App Actions for Windows](/windows/ai/app-actions/actions-json).
