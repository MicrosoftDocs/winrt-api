<!--

## -description

Gets the Package Family Name for the app from which the app action invocation was initiated.

## -property-value

The Package Family name of the app that invoked the app action. For more information, see [An overview of Package Identity in Windows apps](/windows/apps/desktop/modernize/package-identity-overview).
