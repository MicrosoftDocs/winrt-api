# Windows.AI.Actions.ActionRuntime.GetActionEntityById(System.String)

<!--

## -description

Gets the app action entity with the specified ID.

## -parameters

### -param entityId

The ID of the entity to retrieve. The ID is dynamically assigned by the system when the entity is created, such as through one of the [ActionEntityFactory](actionentityfactory.md) entity creation methods.

## -returns

The requested [ActionEntity](actionentity.md) object.
