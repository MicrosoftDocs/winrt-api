# Windows.ApplicationModel.Calls.AppInitiatedVoipPhoneCallOptions.Context

<!--

## -description

Gets or sets a string that's passed to the associated foreground app as a deep link.

## -property-value

A string that's passed to the associated foreground app as a deep link. The maximum length is 128 characters. This member may not be null.
