# Windows.Devices.Haptics.InputHapticsManagerController.TryGetManagerForThread(System.UInt32)

<!--

-->


## -description

Retrieves the [InputHapticsManager](inputhapticsmanager.md) for the specified thread, if one exists.

## -parameters

### -param ThreadId

The ID of the thread.

## -returns

The [InputHapticsManager](inputhapticsmanager.md) for the specified thread, or **null** if one does not exist.
