# Windows.Devices.Haptics.HapticsControllerOverrideToken

<!--
public struct HapticsControllerOverrideToken
-->

## -description

Represents a token returned by [SetOverrideHapticsController](inputhapticsmanager_setoverridehapticscontroller_1943473886.md) that can be passed to [ClearOverrideHapticsController](inputhapticsmanager_clearoverridehapticscontroller_456612938.md) to remove the override.

## -struct-fields

### -field Value

The value of the override token.
