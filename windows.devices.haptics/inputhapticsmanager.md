# Windows.Devices.Haptics.InputHapticsManager

<!--
public sealed class InputHapticsManager
-->


## -description

Provides functionality to trigger haptic feedback on the input device that most recently delivered input to the associated thread. The object must be used on the same thread on which it was created.
